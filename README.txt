MERCÊS CONNECT — PROTÓTIPO DE APRESENTAÇÃO v0.3
Projeto Hórus

COMO ABRIR
1. Extraia o arquivo ZIP.
2. Dê dois cliques em index.html.
3. O protótipo funciona diretamente no navegador, sem instalação e sem internet.

ROTEIRO SUGERIDO PARA A DEMONSTRAÇÃO
1. Visão "Responsável": Home → Comunicado → Confirmar leitura → Conversas → Agenda.
2. Clique em "Escola" no topo.
3. Painel → Criar novo comunicado → Publicar → Acompanhar confirmações.
4. Mensagens → abrir conversa com Maria da Silva → responder/encaminhar.

OBSERVAÇÃO
Este é um protótipo navegável com dados fictícios. Nenhum dado é enviado para servidor ou banco de dados.
